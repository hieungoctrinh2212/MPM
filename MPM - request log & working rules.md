## 1. Working rules (must follow on every task)

### Components & design system

1. **Reuse Mac DS components** before building anything: Table Cell / Table Header (tables), Date Picker + Calendar (dates), Popover content / Menu Item / Command Item (popovers), Dialog / Sheet, Vertical Field, Select & Combobox, Input, Badge, Button (Ghost where asked), Icon Button, Tab (Line variant), Alert, Avatar, Checkbox.
2. **Search Mac DS first** (filter `includeLibraryKeys` to Mac DS) before saying a component doesn't exist.
3. **Use the project's domain components:**
   - Task **State** = `Progress` (`735:10450`): To Do (`State=Low`), In Progress (`State=None`), Done (`State=Medium`), Cancelled (`State=Critical`). No "Review".
   - **Priority** = `Priolity` (`700:8302`): Critical / High / Medium / Low / None.
   - **Selection tag** (e.g. "Tiệm sắp khai trương") = shown as **Button Ghost** with tag icon; picked from a predefined list; **users cannot create or edit tags**.
   - **Filters** = universal local **Filter Bar** (`700:8972`): chips in the `Fillter` slot (Button Group Left "Field:" + Middle value + Icon Button ✕), add-filter icon button, Clear + Save View.
4. **Component architecture:** extract reusable parts into their **own component and nest an instance** (turn on *expose nested instance* + a "Show …" boolean). **Never multiply variant axes** (e.g. State × Priority). Parent variants = only intrinsic states.
5. **Never override styles of DS instances** (fills, strokes…) to patch visuals. Fix the wrapper I built, or report the DS issue.
   - **Approved exception:** in MPM, every **Badge** except `Variant=Outline` has **no border** (instance override `strokes = []`). Apply to every new non-Outline Badge.
6. **Bind every spacing** (padding, gap, wrap gap) to the Mac DS `spacing` collection (3xs=2, 2xs=4, xs=8, sm=12, md=16, lg=20, xl=24, 2xl=32, 3xl=40, 4xl=48, 10xl=144, "hacks to fit scale/6, 10…"). Colors and radii also via variables, no hard-coded hex.
7. Library was updated on 10/08/2026: import DS components **by library key** (e.g. Button `03bcfe72…`, Tab `60de0fbf…`, Table Cell `4428b6e7…`, Table Header `51be275c…`, Badge `368ed840…`, Avatar `bfa99c17…`), resolve property keys by prefix.

### Copy & formatting

8. **Never use "·"**. Write naturally: spaces ("Today 10:32 AM", "#1024  Project"), commas/parentheses ("Overdue (2)", "Overdue, ended 08/31/2026"), numbered captions "1. State".
9. **Dates: `mm/dd/yyyy`, numeric months only** (08/31/2026). Ranges `08/27/2026 → 08/31/2026`, month headers `09/2026`, with time `01/19/2026 06:08 PM`.

### Process

10. Redesign into a **new frame next to the original**; never modify the original.
11. Verify every build with a screenshot; check for clipping, overflow, wrong colors, dark-mode leaks.
12. Ask/confirm when a domain concept is unclear instead of inventing values.
13. **No Spacer frames** in auto layout: use gap **Auto** (space-between); group several items on one side into a "Left" / "Right" auto-layout frame.
14. **Never revert the user's manual edits.** The current state in Figma is the source of truth; if something I built was changed or removed, keep it (ask if unsure).
15. **Buttons are Size=Small or smaller** (Small / Mini), including dialog footers.
16. **Every text uses a Mac DS text style** (paragraph tiny / mini / small / paragraph / large, heading 4–1); never raw font size or weight.
